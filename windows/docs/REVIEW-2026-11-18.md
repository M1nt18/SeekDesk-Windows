# 0.1.5：代码复审与用户测试修复

日期：2026-11-18。基线：`a17fd0aa1bfb77ba59c5ebc9bd26b5557ab108b2`（已发布 0.1.4）。本轮对照外部《SeekDesk Windows 0.1.4 代码复审报告》，并纳入本轮用户提出的红点、图标、刷新、编辑、图片和私有帖问题。下表给出实际改动与验证入口；条件性加固和增量设想不混作已完成的功能。

## 用户测试项

| 问题 | 实现与证据 |
| --- | --- |
| 新版本提示不明显 | App 全程订阅主进程更新状态，初始快照不能盖过更新事件；设置入口和关于页签显示红点，辅助描述保持可访问。`update-notice.test`、`review-interactions-smoke`。 |
| 置顶没有标识、HOT 图形不符 | 使用已解析的 `isPinned` 画绿色圆形图钉，HOT 画红色书签；两种状态独立，普通回复不伪造置顶。截图保存在本地验证目录。 |
| 手动刷新最新帖回到顶部 | 新列表提交后重置滚动与键盘选中项；后台刷新合并头页，不删已追加旧帖，也不回顶。交互回归分别验证两条路径。 |
| 编辑自己的回复报标题无效 | 原因是编辑器一直提交 `title:''`。前端按楼层区分主题/跟帖；后端仅验证主题标题，跟帖请求剔除标题，继续核对 owner 与真实 commentId。接口与原地编辑回归同时覆盖。 |
| 图片经常 fetch failed | 公开样本可复现 302 被旧策略直接拒绝。改用隔离匿名 Chromium 会话处理系统代理/证书，在显式拒绝自动跳转的基础上，逐跳验证最多 3 次公开 HTTPS 跳转；本机、内网、凭据 URL、HTTP 降级仍拒绝。带密钥上传和 Pro API 不跟随重定向。真实图片 IPC 对直连及跳转地址均读取到可显示像素，样本约 1.2–1.5 秒；不把所有网络失败归因于同一原因。 |
| 私有帖误报 RSS 错误 | 官网明确可见的私有提示返回 `accessStatus:private`，不再回退为“不在 RSS”；显示“本帖已经被用户设为私有，您没有阅读权限”。隐藏模板、用户正文引用及普通网络失败不能伪造此状态；继续阅读遇到权限撤销时丢弃旧正文显示。 |

## 性能数据与边界

- 原发布入口 619.60 kB（gzip 206.75 kB）；本轮增加功能后的中间入口约 630 kB；拆分后约 571 kB（gzip 195 kB），另有约 66 kB 整页 chunk。仍有 Vite 500 kB 提示，不通过改警告阈值宣称解决。
- 同一隔离进程中的纯文本 100/500/1000 层样本，点击至 DOM 约 92/265/448 ms；滚动 rAF P95 约 25/13.5/20.2 ms；1000 层渲染进程工作集约 521 MB。后测同阶样本约 97/286/479 ms，未证明千层一次挂载因缩包显著提速或降内存；因此采用自动续读软预算与非活动缓存回收，不夸大结果。
- 25 张合成 800×1600 长图滚动样本中，DOM 同时保留的图片数据节点峰值 1，渲染进程工作集约 218 MB、峰值约 225 MB，rAF P95 约 18.3 ms。这是特定合成内容，不代表真实图片帖内存上限。
- 24 张随机 960×1920 图片及 8 次重复请求，实际主服务/Sharp 读取 24 次，最大并发 2，缓存约 30.84 MB，耗时约 3.6 秒，独立 Node RSS 峰值约 267 MB。该 RSS 包含原始图、转码及分配器，不等于缓存字节，也不等于整个 Electron 桌面的 RAM。
- 慢图、慢后台账号接口及晚到 CSS 的合成 IPC 计时继续运行；正文先读与样式隐藏规则保留。公开图片实测为匿名 GET，未使用用户已有会话。

详细 JSON 与合成截图位于本机 `verification/`；可提交的无个人路径摘要在根目录 `.ecc/benchmarks/`。压力测试不是 SLA 或真实登录验收。

## Pro 支持矩阵及后续项

已验收：静态 DOM 增强、原版菜单/高级设置与 AI 配置的保存确认适配、客户端凭据管理、固定端点主进程绑定、去密脚本偏好导出、实际运行状态。密钥字段在官网只读显示状态。

边界：原版整站备份不支持，直接提示使用客户端去密偏好导出；自定义 AI 地址、NodeImage 官网自动取 Key 不支持。依赖官网 `__vue__` 的动态评论与部分分组快捷回复不因“脚本已运行”就算全部兼容。

Callout、普通代码语言高亮、原生关键词高亮/折叠、自定义历史保留、UID 备注仍为增量设计项，本轮未冒充已实现。连接绑定 DNS 的防御与独立来源签名也仍为专项加固；没有把条件性信号写成已发生的攻击或完成独立安全审计。
