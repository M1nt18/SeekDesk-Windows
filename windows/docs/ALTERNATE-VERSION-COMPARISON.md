## 侧栏尺寸

另一版把默认宽度 250 改为 228、范围 190–390 改为 184–360，并对旧侧栏宽度做有限数值钳制。对照本仓库原版 `Sources/SeekDesk/DeskLayout.swift`，`DeskSidebarSizing` 本来就声明默认 228、范围 184–360、分隔宽度 9。

当前源码通过 `shared/layout.ts` 统一这些值，持久化与设置控件使用同一组常量。有效旧值（例如 250）保留，有限但越界的旧值（例如 390）迁移为 360，其他合法偏好不因侧栏旧值而被一起重置。非数值和非有限值仍拒绝；其他尺寸字段的校验不放宽。

`sidebarBounds(windowWidth)` 复现原版为列表、阅读区与两个分隔预留空间的上界；主界面拖动和重置应引用同一常量，不再保留分散的旧数字。

前端主包还作了独立逐字比对：另一版 `index-CRIv4ooO.js` 比 0.1.1 多 65 个 CRLF 字节；统一换行后长度相同，仅有 5 处侧栏数值差异（默认值、范围和重置值）。新增资料库 UI 位于额外 `reading-tools.js/css`，不是原 React 主包里的其他功能重写。

## 截图模式

另一版 `main.js` 的实际增量只有：解析 `--screenshot` PNG 目标、固定临时 profile、禁用后台节流、非聚焦显示、尝试移到底层、等待 120 帧、`capturePage()` 写 PNG 并退出。它把 `backgroundThrottling:false` 放进了所有主窗口，并复用固定的 `reading-desk-capture` 目录。窗口底层调用是静态观察，不代表该运行库确实支持；当前 45.3.0 没有对应类型接口，因此只采用已验证的非激活显示。

源码合并采用独立 `electron/capture-mode.ts`：

- 仅显式 `--screenshot` 或 `--screenshot=` 才创建截图配置，普通启动不创建临时 profile。
- 准备函数同步返回，以便主进程在 Electron ready 或创建 session 前设置独立 userData。
- 每次创建全新的 `seekdesk-capture-*` 临时目录，不读取已有的论坛 profile；调用者不得再用旧测试环境变量覆盖它。
- 等待本地应用或启动错误界面与 120 个渲染帧，包含超时；检查 native PNG 结果，并独占写入明确选择的新输出文件，不覆盖已存在的图片。
- 后台绘制和不抢焦点的窗口行为只属于显式截图模式，普通启动与正式登录保持现有流程。

这是诊断辅助功能，不是论坛功能验收。截图帧稳定不证明联网数据已全部读完。Windows 下 Chromium 可能在退出前锁住临时 profile，因此没有宣称能在应用运行时删净临时配置；测试及外部调用者可在进程关闭后清理自己创建的目录。

## 前端工具与整合

资料库已移入 `ReadingLibraryPanel.tsx`、`shared/library.ts`、`electron/reading-library.ts`，通过受限主进程 IPC 保存。界面不再靠 DOM 标题猜测当前帖子，不按标题合并不同文章；JSON 仅在用户点击后复制当前账号的资料。

整合时补了直接影响使用的边界：

- 历史访问不改书签原页码、楼层和收藏时间；添加书签是幂等动作，刚启动时的空界面快照不会把已有书签切换删除。
- 清空或移除当前历史后，关闭资料库不会重新填回；真正的新导航或刷新才记录新访问。
- 允许 RSS 的中文分类。尚未确认身份的访客只使用真实公开 RSS 来源的元数据，不能把未知私有页面标题写入公开资料库。
- 旧账号的迟到结果不回填新账号；正常签入账号、公开访客各自独立。
- 一键更新会等待正在执行的显式资料库保存；失败阻止当次安装并保留记录，后台可选历史失败不会永久阻断更新。
- 连续阅读时的刷新、复制链接和新快捷操作以当前可见楼层为目标，不以已经预读到的末页代替阅读位置。

没有读取或自动迁移另一版的个人 localStorage、登录态、Cookie 或历史数据。这里合并的是功能源码。
