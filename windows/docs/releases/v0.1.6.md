## SeekDesk Windows 0.1.6

本版基于 `0.1.5` 及后续消息已读同步与增量更新改动，完成新一轮全量代码审查，重点修复主进程稳定性、网络与安全边界、增量更新交互及渲染层状态一致性问题。

### 增量更新与打包修复

- 修复 `prepare-update.cjs` 的 `.blockmap` 校验（校验常规文件、非符号链接、v2 结构与正整数分块大小）并补齐 `update-manifest` 集成测试。
- 增量下载或校验失败时，在“设置 → 关于”中提供“前往发布页”入口，与失败提示保持一致。
- 修复 `UpdaterService.cleanup()` 在异步检查期间未复核活跃下载/安装状态的竞态，避免误删进行中的更新文件；对齐 `app-update.yml` 缓存目录名。

### 主进程稳定与网络边界

- 修复隐藏读取页/资料页在初始化失败、渲染进程崩溃、调试器断开或命中验证页复用时的卡死循环，异常时自动重建。
- 修复 `anonymousImageFetch` 遇到 `204`/`205`/`304` 空响应体状态码时的同步异常，并在明确的非跳转网络错误时跳过重复请求。
- 修复 `ImageCache` 在长帖快速滚动取消排队任务后未释放等待槽位导致的误报“图片加载队列已满”。
- 扩展热榜、关键词监控、管理记录等公开请求改用独立匿名 Electron 会话，自动沿用 Windows 系统代理与证书。
- 补全图片 SSRF 私有网段检查（含 CGNAT `100.64.0.0/10`、完整 IPv6 链路本地/组播/保留网段与 IPv4 映射地址），并在错误/不支持 MIME 分支取消响应流；动图 Data URI 改为按 `sharp` 实际格式生成 MIME。
- 修复 `Store.commitSettings()`/`save()` 提前快照导致的竞态与 `forum:clear` 绕过写入队列问题；`reply-receipts.json` 防御系统时钟回拨导致的 `submittedAt > acceptedAt` 拒读；加固 `app:window` 与系统通知点击回调的销毁态保护。

### 阅读、草稿与界面交互

- 用户资料轻卡片（点击头像/用户名弹窗）直接显示鸡腿数，无需点进个人主页。
- 修复未填写 NodeImage API Key 时编辑器上传图片缺少醒目提示的问题，新增错误提示条与“填入 NodeImage API Key”直达按钮，打开设置后自动聚焦密钥输入框。
- 修复未就绪草稿卸载后滞留 `detached` 队列、永久阻塞后续退出与更新的问题。
- 引用楼层改用 `DOMParser` 解析纯文本，避免在活动文档赋值 `innerHTML` 触发绕过代理的直接图片请求。
- 修复跨 Portal（`document.body` 与 `#root`）模态层的顶层判定顺序，改按打开栈顺序管理 `inert` 与快捷键。
- 修复长帖图片离屏检测与占位尺寸（对齐 `.reader-scroll` 容器并防止 `0×0` 占位）、图库切图时卸载重建弹窗导致的闪烁与焦点重置，以及图库与渲染层的贴纸/HTTPS 过滤不一致。
- 修复私信列表刷新后 `readIds` 抑制同一联系人后续新未读的问题，统一单会话未读判定逻辑；修复个人空间取消编辑或切页残留废弃草稿、他人头像加载前误显当前账号名、管理记录查询未裁剪空白字符等问题。
- 修复专注阅读模式下隐藏列表抢占方向键/回车键、官方页面按 `Escape` 误清后台标签、拖拽分栏覆盖并发外观设置、关闭标签在 updater 内触发状态更新、回复发送中误阻其他帖子切页存稿、以及评论签名随输入重复解析 Markdown 的性能开销。
- 修复 `PreferenceQueue.replace()` 被在途 `submit()` 覆盖 committed 状态的竞态与 `applyMarkdownCommand` 首行空行偏移，限制已提交回执缓存上限。

### 发布文件

安装版可在“设置 → 关于”检查并增量更新。Releases 提供安装包、`.blockmap` 差分索引、免安装 ZIP、`latest.yml` 与 `SHA256SUMS.txt`。
