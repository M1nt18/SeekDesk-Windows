## SeekDesk Windows 0.1.1

本次按当前原版 README 与 Swift 实现重新核对，处理了 **32 项功能和状态问题**，重点补齐看帖、个人空间、通知与私信。

### 看帖与分页

- **当前页全部作者逐步读取等级**：取消原先 8 人上限，正文先出现，资料后台分批补齐；最多 3 路并发，去重和缓存，失败可重试。补资料不会把阅读位置拉回顶部，合法等级 0 也能显示。
- **帖子上下数字分页**：上方位于楼主正文之后、跟帖之前，下方位于末条回复之后；支持页码、首页和前后箭头，从后页可以直接回第 1 页。只显示真实分页信息，翻页会清除旧楼层定位。
- 补齐公开签名回退、安全的 HTTP/HTTPS 链接与原站时间标签；锁定帖子遵守回复限制，已完成互动按钮不再重复提交，鸡腿操作同步余额，屏蔽内容可展开后再次收起。

### 个人空间与资料

- **恢复实际发帖时间**：个人主题列表从楼主正文补读原始发布时间，显示年月日与时分秒；列表先显示，时间随后补齐，失败可单独重试。
- 恢复默认概况与只读 README、角色标签、统计卡跳转、查看原页及账号设置入口；修复个人活动末页的下一页判断。
- 恢复作者轻资料卡，查看公开等级、角色、统计、加入时间和简介，再进入个人主页或私信；本人私有目录与公开统计按原版权限区分。

### 通知与私信

- 通知三分类分别显示未读数，首次优先打开有未读的分类；选中通知可在通知页预览目标分页中的精确楼层正文，也可打开原帖。
- 私信支持 **Markdown 与纯文本读写**，按原消息模式呈现；纯文本使用普通输入框，切换撰写模式不丢内容，草稿保留模式与图片尺寸。
- 按账号记忆最近与较早联系人，只保存最多 500 个 UID/名称，不额外缓存私信正文；长会话进入和发送成功后定位最新消息。
- 新主题遵循默认编辑器模式；编辑已有主题时保留原阅读权限，只提供实际支持的修改项。

### 草稿与状态修复

- 后台轮询不再覆盖正在编辑的扩展设置，旧设置面板的迟到保存也不会覆盖新面板草稿。
- 记忆收起帖子列表的选择，窄屏临时收起不改用户偏好；关键词命中改回非模态提示，活动窗口中 12 秒自动收起。
- 补强资料、账号摘要、关注和阅读结果的范围检查，防止换页、切换用户或换号后回填旧数据；恢复标签时重新核实内容权限。

### 下载与升级

- 安装版：`SeekDesk-Windows-0.1.1-x64-Setup.exe`。
- 免安装版：`SeekDesk-Windows-0.1.1-x64-portable.zip`，完整解压后运行 `SeekDesk Windows.exe`，保留旁边的资源文件。
- 同页提供对应源码与 `SHA256SUMS.txt`；可用 `certutil -hashfile 文件名 SHA256` 校验。当前 Windows 安装包未进行代码签名。

重新打包的 0.1.0 安装版可在“设置 → 关于”检查更新到 0.1.1；早期没有更新器的 0.1.0 请手动下载安装新版。免安装版请关闭旧进程，再使用完整新包。[0.1.0 发布说明](https://github.com/M1nt18/SeekDesk-Windows/releases/tag/v0.1.0) 继续保留。

### 验证范围

177 项单元与契约测试通过，Electron 的资料/分页、个人空间、通知私信、界面、会话、阅读器、桌面和回复刷新回归通过。论坛写操作、通知已读、私信和图片上传使用隔离测试替身，没有向真实论坛发送测试内容。

匿名公开读取已实测取得正文楼层和真实分页；同一匿名会话的用户资料接口返回 403 站点验证页，线上等级读取仍需在保留的官方窗口完成登录或验证后验收。遇到资料验证时保留正文，并提供重试入口。
