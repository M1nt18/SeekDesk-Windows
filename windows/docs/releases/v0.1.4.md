## SeekDesk Windows 0.1.4

修复客户端读帖慢，以及外部源码审查中尚未解决的数据保护、图片和测试问题，保留现有布局与功能。

### 加载速度

- 正文与样式就绪后即可显示，不再等待整页图片和媒体下载；官网静态资源可复用缓存，同页刷新仍重新读取正文和新回复。
- 账号、通知、个人空间和作者资料使用独立读取队列，后台请求不再拖住正在打开的帖子；等级资料不再初始化另一份完整长帖。
- 普通网络错误不会触发全局 60 秒冷却；真正站点验证继续使用官方窗口完成。
- 本机匿名首页样本从约 6.2 秒降至约 2.3 秒，公开正文约 1.1 秒。公网时间会随网络与验证状态变化，详细复现见审计记录。

### 数据与阅读修复

- 工作区配置损坏或无权读取时显示错误、保留原文件并暂停相关写入，退出不会把旧草稿覆盖成空配置。
- Pro 的 API 密钥等凭据使用 Windows 系统加密保存，旧明文配置自动迁移；加密不可用、解密或写盘失败时保留原配置并提示。
- 图片 URL 替换或图库切到加载失败的图片时，清除上一张图片及尺寸，避免误显示旧图。
- 重新验证 0.1.3 已修复的草稿切换、报告回调、账号恢复隔离、弹窗快捷键及标签清理；外部报告的增量建议单独列出，不冒充已实现。

### 下载与升级

- 安装版：`SeekDesk-Windows-0.1.4-x64-Setup.exe`。
- 免安装版：`SeekDesk-Windows-0.1.4-x64-portable.zip`，完整解压后运行 `SeekDesk Windows.exe`。
- 0.1.2/0.1.3 安装版可在“设置 → 关于”检查并点击“立即更新”，下载、校验、保存后在后台替换文件并自动打开新版。免安装版需手动下载。
- 同页保留 `latest.yml` 和 `SHA256SUMS.txt`；源码在代码仓库与 GitHub 自动归档中提供，不另传源码附件。

### 验证

290 项单元与契约测试、九组审计脚本、完整应用、自动翻页、回复刷新、慢资源/后台排队和真实 Windows 凭据保护检查。打包程序另做隔离启动/重启、安装器载荷、更新文件与隐私检查；未在用户已有安装上执行真实升级。

逐项核对、实测数据及增量建议边界见 [0.1.4 审计记录](https://github.com/M1nt18/SeekDesk-Windows/blob/v0.1.4/windows/docs/REVIEW-AND-PERFORMANCE-0.1.4.md)。
