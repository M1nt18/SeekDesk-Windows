## SeekDesk Windows 0.1.3

保留 `95fb1a3` 的工作区布局与组件拆分，发布本轮审计修复：18 项功能问题、3 项视觉要求回退，以及相应的操作链和失败场景回归。

### 草稿、账号与退出

- 快速切换帖子不再让旧磁盘草稿覆盖刚输入的回复；图片宽度同步更新预览，并随对应草稿保存。
- 回复和私信草稿读取失败时显示重试，保留已输入的文字与尺寸；读取完成后无需再敲一个字才能自动保存。
- 换号同一时刻返回的旧草稿不能进入新账号；启动 IPC 和界面仅恢复帖子位置，旧私有标题、作者等信息须经当前会话重新读取。
- 直接退出和“退出并记住”先保存最新编辑内容及阅读位置，保护防抖保存前的最后几个字。保存拒绝或超时会保留窗口，用户可继续编辑和重试；旧 ACK 不会代替新快照。
- 临时站点验证期间仍可保存最后已确认账号的本机草稿，真实论坛写入继续要求登录；新访客和不同账号不能访问旧稿。

### 阅读与导航

- 调整报告比例不会撤销刚拖动的栏宽；正文缓存保留性能优化，并使用最新操作回调。
- 取消搜索后，旧结果不会接管新页面；弹窗 Esc 不再同时改变底层阅读选择。
- 顶部与右键“关闭全部标签”统一清理阅读位置和续读状态；修复从总览反向切换标签、取消拖拽后的标签定位。
- 保留原有自动刷新、官方页回跳和列表键盘操作，补充列表行、输入法和弹窗的焦点隔离。

### 设置、扩展与界面

- 普通设置、外观、图床密钥/宽度/表情索引、扩展配置在写盘成功后才提交运行状态。失败值不会通过后续保存偷偷生效，失败配置不会启动老板键或自动任务。
- 扩展保存期间继续输入的新值不再被旧提交覆盖；提交期间到达的监控结果继续保留。
- 恢复标题前的版块标签、侧栏文字与填充色、顶栏个人信息扁平背景。
- 浅色/深色、1440/980 窗口、14/28 全局字号八种组合完成布局检查；展开回复后编辑、发送和关闭入口保持可达。

### 下载与升级

- 安装版：`SeekDesk-Windows-0.1.3-x64-Setup.exe`。
- 免安装版：`SeekDesk-Windows-0.1.3-x64-portable.zip`，完整解压后运行 `SeekDesk Windows.exe`。
- 同页提供对应源码、`latest.yml`、`SHA256SUMS.txt`，安装包仍未进行 Windows 代码签名。

**0.1.2 安装版可在“设置 → 关于”检查并点击“立即更新”升级到 0.1.3。** 正常更新后台替换文件并自动打开新版；Windows 权限提示以及两种安装范围并存时的范围选择仍按实际环境处理。0.1.1 使用旧界面的检查、下载及重启按钮；早期没有更新器的旧包和免安装版需手动下载。

### 验证范围

284 项单元/契约测试、八组审计脚本及完整应用回归通过；发布流程另外核对安装包载荷、真正打包程序的启动/重启、隐私内容及更新元数据。Windows CI 增加交互、取消和失败场景检查。

论坛写入、上传和安装调用使用隔离合成数据或测试适配器，没有代用户向真实论坛发送内容，也没有在现有用户安装上执行真实升级。线上账号权限和站点验证仍需在保留的官方窗口下验收。
