## SeekDesk Windows 0.1.5

本版整合 0.1.4 代码复审修复，以及更新提示、评论标识、刷新、编辑回复和图片加载改进。

### 使用体验

- 检测到新版本后，侧栏“设置”和设置中的“关于”显示红点；下载中、待重启及可重试状态继续提示，确认已是最新版本后消失。
- 置顶回复使用绿色圆形图钉，热门回复使用红色 HOT 书签，两种状态分别显示。
- 手动刷新最新帖子回到第一条；后台刷新合并新帖，保留已追加的旧帖和浏览位置。
- 修复编辑本人跟帖时误传空标题导致“标题无效”；跟帖只提交正文，主题标题校验继续保留。
- 私有帖显示“本帖已经被用户设为私有，您没有阅读权限”，不再显示错误的 RSS 提示、作者正文头和回复编辑器。只依据官网明确可见提示识别，引用或隐藏文字不触发。

### 图片与阅读

- 图片使用独立匿名 Chromium 网络通道，沿用系统代理和证书；支持最多三次逐跳验证的公开 HTTPS 重定向，不发送论坛 Cookie，不允许跳转到本机或内网。上传和带密钥的 API 继续拒绝重定向。
- 图片并发转码上限为 2，缓存最多 32 MB，缓存带有效期；相同请求合并，离屏请求可取消，远处图片释放数据并保留占位，避免长期累计大量图片。
- 原图真正加载和解码后才显示已加载；失败保留预览，可重试。图库支持键盘操作，缩略图可用键盘打开，关闭后归还焦点。
- 保存逻辑块阅读锚点，慢图重排、切标签或缓存回收后继续原段落；用户操作会立即停止自动位置校正。
- 自动续读到 500 层或正文预算后暂停，可继续下一批，也可直接用页码跳转；已加载楼层不删除。回收非活动正文缓存，保留标签、草稿和阅读位置。
- 关闭“只看楼主”会清除旧筛选造成的空页暂停；回复后的后台重读尊重用户随后选择的页码。

### 数据、账号与 Pro

- 损坏或无权读取偏好文件时保留原文件并暂停写回；不可解密的图床密钥密文不会因修改宽度被清除。
- 草稿、联系人和设置使用确认提交状态；连续保存失败不会回滚到未提交值。楼层引用先与迟到的旧草稿合并，避免覆盖原文。
- 已发布回复记录不含正文的本机回执；清理失败可重试，旧稿不会因此被误认为未发送，重试不再次发帖。
- 关键词监控由单一调度器续排，无关设置不再中断轮询；停用与旧响应失效保护保留。
- 手动检测会话读取新官网文档；清会话时立即废止旧账号权限，工作区保存失败不再恢复旧身份。
- Pro 的实际 API 密钥仅在客户端录入和保存；官网表单只显示配置状态，主进程仅为固定 OpenAI/NodeImage 操作绑定凭据。
- Pro 设置表单等待写盘确认后再应用并提示；客户端支持去密脚本偏好导出，原版整站备份明确标为不支持。显示准备中、运行中、待验证、失败等运行状态。
- 模态层覆盖普通与确认弹窗，支持双向 Tab、Esc、Ctrl+W 及焦点归还。Markdown 的 Tab 可离开编辑器，缩进改用 Alt+]；分栏支持键盘调整，30 项标签菜单可滚动。

### 验证与升级

构建、单元/契约测试、完整应用、交互审计、回复/编辑、自动续读、真实 Windows 凭据保护与图片读取均另有验证记录。论坛写入使用合成夹具，不向真实论坛发送内容；真实登录仍由用户操作官网窗口。

安装版可在“设置 → 关于”检查并立即更新。Releases 提供安装包、免安装 ZIP、`latest.yml` 与 `SHA256SUMS.txt`，不另外上传源码 ZIP；代码仓库与 GitHub 自动源码归档保留。

逐项证据、性能样本与兼容边界见 [本轮核对记录](https://github.com/M1nt18/SeekDesk-Windows/blob/v0.1.5/windows/docs/REVIEW-2026-11-18.md)。
