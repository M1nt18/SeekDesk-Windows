## SeekDesk Windows 0.1.2

整合本地阅读资料库、自动续读和一键更新，并继续按原版源码补齐个人资料、通知私信、编辑器及扩展的布局与状态关系。

### 阅读与标签

- 评论接近底部自动加载下一页，追加已读内容；楼主与跨页 HOT 回复去重，保留真实操作页和阅读位置。失败可重试，连续两页没有新增可见评论时暂停并提供“继续加载”。
- 单页帖子不显示上下分页；有第二页时保留数字页和首页直达。刷新、复制链接以当前可见楼层为目标，重开可恢复楼层内偏移。
- 标签使用统一宽度，长标题省略并保留完整提示，支持横向滚动、拖动、右键左右移动与关闭；选中标签滚入视口。
- “写回复”移至右侧；恢复楼层回复分区、只看楼主空态、阅读权限/私有与锁定提示、独立角色标签、帖子右键及屏蔽标识。

### 本地阅读资料库

- 本地书签、最近 200 条历史、标题/作者/编号搜索、移除/清空与 JSON 复制，按账号及公开访客隔离，仅保存帖子元数据，不修改论坛收藏。
- `Ctrl+Shift+B` 收藏当前帖子，`Ctrl+Shift+L` 打开资料库，`Ctrl+Shift+P` 打开快捷操作；可直接打开原生阅读中的指定页和楼层。
- 书签保存的位置不随历史访问变化；重复收藏不会误删旧书签，清空历史后关闭面板不会复活刚删记录。侧栏默认 228、范围 184–360，兼容已有有效设置。

### 个人资料、通知与写作

- 个人介绍、签名及 README 统一使用安全 Markdown，补齐表格边线、表头、间距、横向滚动、列表、代码与链接；五项统计恢复常态背景。
- 资料无修改时禁用保存，刷新不覆盖编辑；成功回概况，本人签名和关注状态同步回阅读区。
- 通知/私信保持联系人与右侧详情分栏；预览和标已读分开，切换前保存草稿，保留纯文本/Markdown 和精确楼层预览。
- 楼层原地编辑复用权限与写入链；图片上传中禁止提前发送，发送期间锁定相关控件，旧结果不会清掉后来修改的新稿或抢回导航。
- 服务端已接受后的提交快照与本机草稿协调，区分“已提交”与“本机清理失败”，减少离开、重开页面时误重复发送；用户明确新写相同内容仍可正常提交。
- 官网隐藏正文不会因清洗 style 而变成可见，未知互动数不伪造为零；游客操作转官方登录，锁定帖遵守回复限制。

### 更新、设置与扩展

- 安装版发现新版本后点“立即更新”，后台下载、SHA-512 校验，等待编辑内容、阅读状态与正在保存的资料库操作完成，再安装并自动重启；无需手动打开网页或运行下载文件。
- 正常更新保留真实安装进度，跳过选择和完成步骤；同时存在当前用户/所有用户两份安装时保留范围选择，避免替换错副本。系统权限提示仍按 Windows 处理。
- 取消、校验或保存失败不会继续安装，已校验包可复用，更新缓存继续自动清理；启动检查和恢复缓存本身不会自动安装。
- 恢复自动检查更新开关，以及扩展中心分组、整页详情、状态色块和停用/移除后的操作关系。
- 新增显式截图诊断 CLI，使用全新临时配置、稳定帧等待及独占 PNG 输出；保留 Electron 45.3.0 与既有安装更新链。

### 下载与从旧版升级

- 安装版：`SeekDesk-Windows-0.1.2-x64-Setup.exe`。
- 便携版：`SeekDesk-Windows-0.1.2-x64-portable.zip`，完整解压后运行 `SeekDesk Windows.exe`。
- 同页提供对应源码、`latest.yml` 和 `SHA256SUMS.txt`。可用 `certutil -hashfile 文件名 SHA256` 核对，安装包仍未进行 Windows 代码签名。

**从 0.1.1 升到本版，仍使用旧界面的“检查更新 → 下载更新 → 重启并安装”。装好 0.1.2 后，后续版本可点“立即更新”。** 重新打包的 0.1.0 安装版也可检查新版；早期没有更新器的旧包请手动安装一次。便携版继续手动下载完整新包。

### 验证范围

253 项单元与契约测试、完整应用及资料库/连续阅读/编辑器/私信生命周期等隔离回归通过。发布前另外检查实际安装包载荷、打包程序启动、版本元数据与隐私内容。

论坛写入、上传及原生安装调用使用合成数据和测试替身；没有代用户向真实论坛发送测试内容，也没有在用户现有安装上执行升级。真实登录权限、站点验证与资料接口仍需在保留的官方窗口处理。
