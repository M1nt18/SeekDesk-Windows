## 逐段核对范围

- `WorkspaceView.swift`：顶部账号/通知/老板键入口，首页排序、列表状态、搜索用户结果、列表行与右键动作。Windows 对应 `App.tsx` 的 toolbar、sidebar、列表、搜索和布局状态。
- `ForumAccountSheet.swift`：读取状态、账号版本守卫、分类未读、通知选中、标已读、近期/较早联系人、私信分栏、对话读取、发送和原消息 Markdown 模式。Windows 对应 `NotificationsPanel`、`NotificationPreview`、`DirectMessageBody` 以及既有 query/write 接口。
- `NewDiscussionView.swift`、`MarkdownComposer.swift`：真实版块/权限、内版发布确认、发送快照、上传、格式工具、视图切换、撤销重做、清空、表情和图片设置。Windows 已有格式/模式/上传接口；此次新确认的遗漏是父级发送门槛及发布期间状态关系，不能将内部编辑器锁定视作整个发帖流程锁定。
- `PluginCenterView.swift`：安装/启停/移除、八项扩展控制与关键词草稿。Windows 八项扩展和设置处理链均存在；原版为“未安装/已安装”分组卡片及整页详情，Windows 仍为统一网格和弹窗详情，属于需要在视觉复刻中继续明确核对的布局差异，不在本次六项行为问题内冒充已修复。
- `PreferencesPane.swift`：通用、阅读、外观、关于四分类，发送快捷键、自动刷新、自动加载旧帖、字号/报告缩放、主题与品牌、栏宽。Windows 有对应持久化设置字段与界面调用；原版 Sparkle 的“自动检查应用更新”开关在 Windows 尚没有同名控制，Windows 是自动定时检查加手动触发安装，需作为明确的设置差异保留记录。
