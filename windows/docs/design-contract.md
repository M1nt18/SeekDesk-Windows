# Windows 界面验收约定（用户测试修订）

目标是让 NodeSeek 用户扫描帖子、保留多篇阅读标签，并在官方窗口完成需要账号的操作。参考上游 SeekDesk 的侧栏、列表、正文三栏布局；使用 Windows 字体和窗口控制，采用克制蓝色强调与中性背景，优先保证标题和正文可读。

目标视口：1440x920、980x720。最小窗口 960x680，窄窗口可收起帖子列表。设置页保持返回阅读入口。

本轮新增要求：分类标记与帖子标题同行，时间归作者行，默认尺寸 fixture 一屏至少 7 条完整帖子；仅顶部正中保留 SeekDesk 品牌。默认菜单至少15px、标题16px、正文18px，辅助文字最少12px；全局14–24与正文14–40可分别调整，窄屏不能靠缩小字号解决。高字号允许自然换行与面板滚动，可收起列表专注阅读。

总览与普通标签一致可关闭，关闭状态可恢复；账号、列表和楼层头像必须传入真实来源，网络失败才用占位。回复与用户操作有明确发送状态、失败保留输入和费用确认。NodeSeek Pro只在内嵌官网运行，状态与React功能分别表述。

主操作是选择帖子、切换/关闭标签、刷新和打开原帖。公开来源、读取时间、摘要范围必须明确标注；不把空 RSS 版块误称为没有帖子，不把账号未检测误称为已登录。

状态约定：loading 保留布局与加载提示；empty 解释当前筛选/来源范围并提供刷新或官方入口；error 提供原因和重试；partial 显示真实 RSS 可用内容和完整阅读入口；success 显示来源和抓取时间；permission 提供官方登录/验证窗口与返回后检查入口。设置保存反馈可见，所有图标按钮有标签、键盘焦点可见，跟随系统 reduced-motion。

首版验收包括真实公开读取、两种尺寸渲染、主题与字号保存、标签恢复、官方远端内容隔离、持久分区会话（用无凭证测试 Cookie 验证存储）、安装程序安装后启动。真实账号登录和受权限保护内容由用户在官方窗口操作，未登录验证不能替代这项验收。

本轮不打包：用源码生产构建运行真实Electron；隔离mock覆盖回复/关注/私信和脚本行为，不向真实论坛提交测试内容，已有安装程序保持不变。
