# 桌面行为与更新：0.1.0 重新打包说明

本轮版本仍为 0.1.0，已重新打包并替换同一 GitHub 发布页的安装版、免安装版、配套源码与 SHA-256 校验文件，补充 `latest.yml` 更新清单。下列修改已包含在重新打包的下载文件中。

早前下载的 0.1.0 旧包没有更新器，同版本也不会自动升级，须重新下载并手动安装一次；之后安装版可在线更新到更高版本。免安装版继续手动下载。配套源码归档从实际构建提交的已跟踪文件生成，安装包仍未进行 Windows 代码签名。

## 关闭与窗口记忆

- 默认点击关闭或系统关闭事件时，询问“最小化到托盘 / 退出程序 / 取消”，可记住选择；取消不保存选择。
- 托盘图标和菜单可恢复窗口或明确退出；托盘创建失败时退回任务栏最小化。
- 通用设置可随时改回“每次询问”。正常窗口尺寸、位置和最大化状态自动保存；显示器变化时限制到可用工作区。
- 显式退出及更新安装不再弹第二次关闭询问；退出前完成窗口和应用偏好的保存。

## 安装器快捷方式

`build/installer.nsh` 在目录页后添加桌面与开始菜单快捷方式复选框，默认勾选。普通重装按选择重新创建缺失图标；静默安装按默认值创建；更新安装保持既有快捷方式状态。

`scripts/check-installer-options.cjs` 用真实 electron-builder NSIS 模板分别编译安装器/卸载器分支，不执行安装。安装器经过静态载荷与模板验证；本轮未实际运行安装向导或执行完整重装。

## 在线更新与缓存

- 使用公开稳定仓库 `M1nt18/SeekDesk-Windows`，使用独立网络会话，不带论坛 Cookie 或维护者令牌。
- 安装版启动后检查更新，每日再次检查；用户手动下载、取消或确认安装。关闭时不会静默安装。
- 新发布必须提供完整 x64 安装程序及 `latest.yml`，下载后和安装前都校验 SHA-512。
- `npm run dist` 仅在本地打包，并生成 `release/latest.yml`；强制 `--publish never`，不会自动上传。本次发布附件已同时提供安装程序与清单，后续发布也需保持配套。
- 早前下载的 0.1.0 旧包没有更新器，同版本也不会自动升级；先手动安装这次重新打包的版本，之后安装版才可通过更新器升级到更高版本。
- 开发版与免安装版可查看公开版本，在线安装被禁用，提供本仓库手动下载入口。清单缺失时不会把任意下载链接当可安装更新。
- 只清理用户数据目录内的 `updater-cache-v1`。下载失败或取消会清理残留；保留待安装的当前包、下载中的文件和仍在使用的安装器。
- 新版启动后确认旧安装器退出，再清理旧包；若安装向导仍开着，每 60 秒重试。其他过期缓存按七天和 512 MB 上限清理，不触及账号、草稿或用户下载目录。

## 热门回复和编辑器

- 保留官方 `hot`、`pined` 标记及跨分页楼层；主楼始终在最前，热评/获鸡腿回复优先，保留同组原顺序。
- 回复右上角显示红色 HOT 标识。跨页互动与引用使用该楼层实际所属页面，重复楼层只显示一次。
- 展开的回复编辑器右上角可关闭，关闭仅收起，草稿仍然保留。
