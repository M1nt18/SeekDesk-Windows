# 设置与扩展中心源码复核（2026-11-14）

本记录覆盖此前核对遗漏的扩展目录/详情布局，以及自动检查应用更新偏好。没有把已经存在的按钮名称当成真实功能验收。

## 原版依据与本轮实现

| 原版实现 | Windows 修复 |
| --- | --- |
| `PreferencesPane.swift:86-90` 提供“自动检查应用更新”与独立手动检查 | 通用设置恢复开关，默认开启，随本机桌面偏好保存。关闭停止启动及定期检查，保留手动检查、已授权的一键更新和独立缓存清理。 |
| `PluginCenterView.catalog` 将全部扩展分成“未安装”“已安装”，默认显示已安装 | 目录恢复分组、数量、空目录入口；未安装卡片使用虚线边框，已安装卡片使用填充背景。 |
| `PluginCenterView.card` 有单色图标和状态胶囊 | 恢复对应的火焰、签到、表格、计算、用户、广播、盾牌图标；启用/停用/未安装状态独立显示。 |
| `PluginCenterView.detail` 是整页详情，页首可返回扩展中心 | 移除详情模态窗口，保留顶部返回、当前扩展标题、说明、安装/启用、配置、来源与移除操作。 |
| 原版详情保留原作者、脚本与后端来源链接 | 恢复热榜与管理记录的真实来源链接；自有计算器仍按用户要求打开原指定站点。 |
| `DeskExtensions.remove` 关闭签到自动任务及关键词系统通知 | 移除对应扩展时同步清除这两个开关，重新安装不会意外重新启动先前的自动行为。停用的办公视图、计算器、管理记录执行按钮，以及签到自动项和关键词系统通知遵守扩展启用状态。 |

已有本地配置草稿和异步保存会话守卫继续保留。后台签到/关键词状态更新不改用户正在输入的配置，扩展 A 的迟到保存也不能覆盖新打开的扩展 B。
