# 用户测试修正（源码，未打包）

## 1. 登录后官方页面与客户端分离

官方页面从独立 BrowserWindow 改为主窗口阅读区的 WebContentsView，保留隔离会话、无 Node.js、无应用 IPC。官方站内弹窗继续在同一视图导航，登录目的跨重定向保留。

确认登录成功后自动返回 React 阅读界面，更新账号并刷新原来的版块。旧账号/未登录状态的迟到请求会失效，也不会再把验证冷却写回；普通官方网页浏览则等待用户点“返回阅读”。切换设置、版块或帖子时隐藏官方视图。

验证：真实官方登录页面嵌入、单个可见主窗口、1440/980 宽度与宿主区域一致、切换设置无原生覆盖；隔离模拟登录验证自动返回、交易版块自动刷新、旧读取被拒绝、普通浏览不误关闭。结果见 `verification/embedded-login-smoke.json`。

仅执行 `npm run build` 编译源码，并未运行安装包/源码包打包命令，release 中已有安装程序 SHA-256 保持不变。真实账号登录由用户自行完成，回归脚本使用全新的隔离配置，不读取用户已有 Cookie。

继续测试：退出原有版本后，双击 windows 目录的“启动调试版.cmd”，或运行 `npm start`。这会启动本次已编译的源码，不需要安装包。修改源码后先运行 `npm run build`，实时开发可用 `npm run dev`。
