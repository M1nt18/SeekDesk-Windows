# SeekDesk Windows 0.1.1 · 开发说明

使用 Electron、React 和 TypeScript 移植 SeekDesk V1.0.0。上游参考提交为 `84e99c6cb24e66c5bbccb6382380ae72b9924d4b`，父目录的 Swift 源码保持原样。界面以四张原版截图为参考，保留原版导航和工具。

详细功能、截图和首次使用指南见 [仓库首页 README](../README.md)。

已打包的安装版和免安装版见 [v0.1.1 发布页](https://github.com/M1nt18/SeekDesk-Windows/releases/tag/v0.1.1)。开发者首次获取或更新源码后执行 `npm ci` 和 `npm run build`；已有编译结果时可双击“启动调试版.cmd”运行。

0.1.1 补齐阅读分页、全员等级读取、个人空间实际发帖时间、通知详情与私信模式等 32 项问题，见 [更新说明](docs/releases/v0.1.1.md)。重新打包的 0.1.0 安装版可检查更新；早期没有更新器的旧包请手动下载安装新版，免安装版继续手动下载。配套源码归档来自实际构建提交，发布附件同时提供 `SHA256SUMS.txt` 与安装版更新清单 `latest.yml`。

## 当前功能

- 左侧发帖、最新帖子、论坛版块、快捷功能、热榜，以及友情链接、我的、扩展中心、设置；顶部搜索、布局、通知、账号、等级和鸡腿余额。
- 官网列表、最新回复、精品区、筛选、分页和 RSS 备用；多标签、后台打开、拖动排序、关闭总览、分栏拖动和阅读位置恢复。
- 逐楼头像、等级、角色、签名、引用、跳转、分页、只看楼主；图片查看器、表格、完整 ANSI/xterm 终端与 NQ/TQ 报告及独立缩放。
- 当前页全部可识别作者后台逐步读取等级，不再限制 8 人，失败可重试且不阻塞正文；帖子顶部和底部提供数字分页及首页直达。
- 新主题、编辑本人主题/评论、回复、关注、私信、点赞、鸡腿和点踩确认；统一 Markdown 工具、对照预览、图片上传、剪贴板图片、官方与本机分组表情、发送前图片调整。
- 浏览时回复编辑器默认收起，点击醒目的“写回复”或楼层操作展开。发布后按官方返回定位新楼层；短暂同步延迟仅重试读取，不重复发送。隐藏读取页禁用缓存，同页楼层链接也会重新取正文。
- 个人主题/评论/关注/粉丝、个人 README 和签名编辑、通知分类、完整私信会话、UID/主页链接打开私信；按已确认账号保存草稿与图片尺寸。
- 个人空间默认概况、只读 README、作者轻资料卡、精确到秒的实际发帖时间；通知预览精确楼层，私信支持纯文本/Markdown 及按账号记忆较早联系人。
- 八项扩展：热榜、签到、老板键、剩余价值计算器、屏蔽用户、只看楼主、关键词监控、管理记录查询。计算器按用户要求内嵌 [sy.3xme.com](https://sy.3xme.com)，使用独立持久存储保留输入；热榜可配置默认榜单、侧栏条数、刷新间隔和热度分值显示。
- 四类设置、六色品牌与运行任务栏图标、全局 14–28 字号及各阅读区域独立大小；NodeSeek Pro 1.0.8 继续可在内嵌官方页面运行。
- 关闭主窗口时询问最小化到托盘、退出或取消，可记住选择；自动恢复窗口尺寸、位置及最大化状态。
- NSIS 安装器提供默认勾选的桌面和开始菜单快捷方式选项，普通重装可修复缺失图标；安装版支持 GitHub 稳定发布更新、校验、取消、重启续装与应用更新缓存清理。
- 热评/获鸡腿回复优先，跨页热门楼层带 HOT 角标；回复编辑器右上角关闭后保留草稿。

本轮逐项源码和验证对应关系见 [0.1.1 核对清单](docs/parity-audit.md)，较早记录保留于 [功能移植清单](docs/FEATURE-PARITY.md)。

## 登录与数据

通过右上账号进入客户端内的 NodeSeek 官方登录页，由用户完成登录或人工验证。登录与后台读取共享 `persist:nodeseek` 会话；登录弹窗留在同一个主窗口，识别成功后返回 React 界面。官方网页中的帖子可回到阅读标签。

RSS 只有最近公开内容，界面明确标记摘要；它不提供完整历史、回复或账号权限。官网验证与访问权限由站点决定。

Windows 数据默认位于 `%APPDATA%/seekdesk-windows`：`preferences.json` 保存阅读偏好，`workspace-features.json` 保存扩展、搜索和按账号隔离的草稿，Chromium 管理论坛会话。图片密钥经 Electron safeStorage 使用 Windows DPAPI 加密，应用接口不将密钥返回界面。本机草稿不等同于加密保险箱。

NodeImage 上传需要用户配置自己的 API Key。普通图片支持调整发送宽度；动图保留原尺寸。阅读大图使用像素预算和有限缓存，自定义表情本机总大小上限为 64 MB，预览使用缩略图，插入时才上传原文件。

自动签到、关键词轮询和老板键依赖应用运行；老板键为 `Ctrl + Shift + 配置字符`。NodeSeek Pro 首次关闭，脚本来源与适配说明见 [NODESEEK-PRO.md](docs/NODESEEK-PRO.md)。

## 开发与验证

Windows 10/11 x64，Node.js 22.12+。在本目录使用 cmd.exe：

```bat
npm ci
npm run build
npm start
```

`npm run dev` 启动开发模式；`npm run build` 仅编译和类型检查，不生成安装包。

```bat
npm test
npm run test:app
npm run test:public
npm run test:feedback
npm run test:reply-refresh
npm run test:desktop
npm run test:installer-options
```

- `npm test`：解析、权限、账号隔离、草稿、Markdown、ANSI、图片链接、扩展调度、金额/日历与搜索回归。
- `test:app`：真实 Electron 中的主进程/预加载桥、界面操作、富内容、登录弹窗回跳测试，使用隔离用户目录。论坛写入与图片上传全部由测试替身拦截。
- `test:public`：实际匿名读取公开 RSS、榜单、管理记录和汇率，不向真实论坛提交内容。
- `test:feedback`：本轮 10 项反馈的 9 组界面/持久化回归，含真实 sy.3xme.com 计算、MD 输出和输入恢复；报告及深浅主题截图在 `verification/feedback/`。
- `test:reply-refresh`：跨页回复定位、延迟同步时只读重试、只看楼主下的新回复可见性及刷新读取回归；全部论坛请求使用隔离替身。
- `test:desktop`：隔离配置中的关闭与托盘、窗口记忆、热门回复和编辑器关闭回归；更新器使用隔离缓存与可注入适配器验证取消、校验、重启恢复和缓存清理。
- `test:installer-options`：使用 electron-builder 的 NSIS 模板编译安装器/卸载器分支，不执行安装。

0.1.1 的 177 项单元/契约测试通过，并完成资料/分页、个人空间、通知私信及既有界面回归。真正打包的 0.1.1 程序已用隔离配置启动与重启验证，安装器载荷静态核对通过；未在使用者系统执行真实安装或升级。匿名正文读取成功，资料接口返回 403 验证页，线上等级仍需在官方窗口登录或验证后验收。详细范围见 [核对记录](docs/parity-audit.md)；旧桌面改进保留于 [重新打包说明](docs/DESKTOP-UNRELEASED.md)。

报告与截图写入 `verification/`。真实账号的登录、权限和发帖结果仍需用户在官方会话下验收；测试没有使用用户已有的 Cookie，也没有向真实论坛发送测试帖子、回复、私信、互动或签到。

发布包使用明确的文件白名单，不包含测试配置、运行日志或源码映射。`scripts/audit-release.cjs` 检查实际 ASAR/依赖和隐私内容；`scripts/check-installer.cjs` 静态解包安装器并核对载荷；`scripts/release-smoke.cjs` 用全新隔离配置运行真正打包的程序。源码归档通过 `git archive` 仅包含已提交文件。
