# SeekDesk V1.0.0

SeekDesk 首个公开版本：在 Mac 上，舒服地逛 NodeSeek。

## 主要功能

- 原生多栏、多标签阅读，支持后台打开帖子、返回总览、收起列表与键盘导航。
- Markdown 编辑、对照预览、图片上传、表情、引用、私信与通知。
- NQ / TQ 报告独立缩放，长图按比例展开，完整彩色终端报告与复制。
- 按账号隔离和恢复回复、私信、新主题草稿及图片设置。
- 热榜、每日签到、剩余价值计算、屏蔽用户、只看楼主、关键词监控、老板键和管理记录等内置扩展。
- 六色品牌外观、明暗主题和独立阅读尺寸设置。
- 新增“设置 → 关于”：V1.0.0 / 构建 70、官网、GitHub、反馈、许可和第三方客户端声明。

发布前已修复并验证账号草稿隔离、会话缓存失效、旧异步请求写回、草稿持久化、私信未读聚合、长图解码、Markdown 图片解析、报告截断、资料缓存与失败重试九组问题。

## 下载与安装

适用于 Apple Silicon Mac，最低目标系统为 macOS 14。下载 `SeekDesk-1.0.0-macOS-arm64-unsigned.dmg`，打开后将 SeekDesk 拖入 Applications。

首版使用临时签名，**没有 Apple Developer ID 签名或 Apple 公证**。如果首次启动被 macOS 阻止，请在确认来源后进入“系统设置 → 隐私与安全性”选择“仍要打开”。不需要关闭系统 Gatekeeper。

下载同一发行页的 SHA-256 文件后，可在下载目录执行：

```sh
shasum -a 256 -c SeekDesk-1.0.0-macOS-arm64-unsigned.dmg.sha256
```

后续版本通过 GitHub Releases 手动更新；替换前请先退出应用。
